One letter, one answer: coffee or tea. This program writes exactly one character to `/output/entry.txt` — **A for coffee** — and nothing else. Coffee is the first letter and the first drink of the day: the bold, wide-awake default, the fuller and more alive stance of the two. Tea is the calm second; coffee is the jolt that starts the morning. Deterministic, Python 3.13 standard library only, no network, no secrets.

## Run it

```sh
python3 main.py
```
